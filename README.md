# xbox_Game_Pass_Subscriptions_Sales_Dashboard_Excel
Dashboard interativo em Excel que analisa 295 assinaturas do Xbox Game Pass em 2024. Responde a 8 perguntas de negócio sobre receita, ticket médio, planos, periodicidade, renovação automática, passes de temporada, cupons e evolução mensal, com tabelas dinâmicas, gráficos e segmentações de dados.
